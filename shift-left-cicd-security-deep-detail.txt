2) What “Shift-Left” Means in This Repo Context

Traditional model:
- Build fast -> security later (often too late).

Shift-left model (what this repo showcases):
- Write code -> PR triggers checks -> vulnerabilities found immediately -> merge blocked if risk unacceptable.

Why this matters:
- Fixing security bugs earlier is much cheaper.
- Developers receive feedback in the same workflow they already use (PR/CI).
- Security stops being a one-time audit and becomes a continuous engineering control.

2. Pipeline executes unit/lint/build checks.
